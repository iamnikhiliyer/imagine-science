# Working on Imagine Science

- Preserve the user's film source and supplied assets.
- Read `SPEC.md` for the initial scope and the skill's references for film work.
- Motion must be determined by frame state; seed intentional randomness.
- Label measured, simulated, illustrative, and generated material accurately.
- Never claim scientific validation from visual scores or media verification.
- Run `npm run check` and `npm run build` for code changes. Render and inspect
  affected frames for visual changes. Run the example export/verification path
  when changing media or render helpers.
- Keep private assets, credentials, machine-specific paths, and generated exports
  out of Git. Keep related Remotion package versions aligned.
